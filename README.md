# 🎵 Afro MIDI Pack Generation X

Generate MIDI files for popular Afrobeats songs with ease!

## 📦 Currently Included

- **Dumebi by Rema** - F# minor bass line at 105 BPM

## ⚡ Quick Start

### 1. **Install Dependencies**
```bash
pip install -r requirements.txt
```

### 2. **Run the Generator**
```bash
python dumebi_bass.py
```

### 3. **Get Your MIDI File**
The script will create `dumebi_bass.mid` in your directory. Download it and use it in any DAW!

## 🎹 Supported DAWs
- FL Studio
- Ableton Live
- Logic Pro
- GarageBand
- Reaper
- Studio One
- Any DAW that supports MIDI files

## 🎯 How to Use the MIDI File

1. **Open your DAW** (FL Studio, Ableton, Logic Pro, etc.)
2. **Import the MIDI file** into a track
3. **Assign a bass instrument** to the track
4. **Adjust tempo/key** as needed
5. **Start producing!**

## 🔧 Advanced Options

Want to modify the MIDI file? Edit these values in `dumebi_bass.py`:

```python
num_bars = 8  # Change number of bars

tempo_in_microseconds  # Adjust BPM
```
